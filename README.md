# Laboratory 05 - Cloud Data Engineer

**Student:** Francisco Abaquita

## Mission Overview

This laboratory explores cloud storage types and documents a proof-of-concept deployment of MinIO, an S3-compatible object storage server. The scenario is a photo-sharing application that needs durable, scalable storage for user-uploaded images outside ephemeral application containers.

## Objectives

- Compare block, file, and object storage.
- Deploy MinIO with Docker and access its web console.
- Create a `client-photos` bucket and upload a sample object.
- Record the deployment and reflect on the storage concepts.

## Tools Used

- KillerCoda Ubuntu/Docker playground
- Docker
- MinIO
- Web browser
- GitHub and Markdown

## Skills Learned

- Distinguishing storage models and their use cases
- Running a containerized storage service
- Accessing a service through forwarded ports
- Organizing objects in a bucket
- Documenting cloud infrastructure operations
